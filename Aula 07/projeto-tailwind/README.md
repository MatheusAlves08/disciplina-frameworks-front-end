# 🚀 Projeto Dashboard - Tailwind CSS

Projeto desenvolvido para a disciplina de **Framework Front-End (Aula 07)**. Aplicação web estilo **Dashboard de Gerenciamento** construída com HTML5 e estilizada utilizando mais de 30 classes utilitárias do **Tailwind CSS**.

## 📚 Tabela de Classes Utilizadas e Suas Funções

Abaixo está a documentação detalhada das **mais de 30 classes do Tailwind CSS** aplicadas no projeto, categorizadas por funcionalidade:

| Categoria | Classe | Função / Descrição |
| :--- | :--- | :--- |
| **Cores de Fundo** | `bg-slate-900` | Define a cor de fundo principal com tom escuro Slate 900 |
| | `bg-slate-800` | Define a cor de fundo dos cards e containers |
| | `bg-indigo-600` | Define o fundo de botões principais com azul/índigo |
| | `bg-emerald-500` | Define a cor de indicadores positivos e barras completas |
| **Gradientes** | `bg-gradient-to-r` | Aplica gradiente de cor da esquerda para a direita |
| | `from-indigo-900/50` | Define a cor inicial do gradiente com transparência |
| | `to-slate-800` | Define a cor final do gradiente |
| | `bg-clip-text` | Recorta o fundo gradiente no formato do texto |
| **Tipografia & Cores** | `text-slate-100` | Define a cor do texto principal em tom claro |
| | `text-indigo-400` | Aplica cor destaque azul/índigo nos textos |
| | `text-emerald-400` | Aplica tom verde para métricas positivas |
| | `text-amber-400` | Aplica tom amarelo para alertas |
| | `text-transparent` | Torna o texto transparente para exibição de gradiente |
| **Tamanho & Peso do Texto** | `font-sans` | Utiliza a família de fontes sans-serif padronizada |
| | `font-bold` | Aplica peso negrito ao texto |
| | `font-extrabold` | Aplica peso extra-negrito (títulos e destaques) |
| | `text-xs` | Define tamanho de texto muito pequeno (12px) |
| | `text-sm` | Define tamanho de texto pequeno (14px) |
| | `text-xl` | Define tamanho de texto grande (20px) |
| | `text-3xl` | Define tamanho de texto extra grande (30px) |
| | `text-4xl` | Define título principal responsivo (36px) |
| | `uppercase` | Transforma o texto em letras maiúsculas |
| | `tracking-tight` | Reduz o espaçamento entre letras (letter-spacing) |
| **Espaçamento (Padding/Margin)**| `p-6` | Adiciona padding interno de 1.5rem (24px) |
| | `px-4` | Adiciona padding horizontal (esquerda/direita) de 1rem |
| | `py-3` | Adiciona padding vertical (topo/base) de 0.75rem |
| | `mx-auto` | Centraliza o container horizontalmente com margens automáticas |
| | `space-y-4` | Adiciona espaçamento vertical uniforme entre elementos filhos |
| | `space-x-3` | Adiciona espaçamento horizontal uniforme entre elementos filhos |
| **Dimensões & Formatos** | `w-full` | Define a largura em 100% |
| | `max-w-7xl` | Limita a largura máxima do container principal |
| | `min-h-screen` | Define a altura mínima como 100% da viewport |
| | `w-10 h-10` | Define largura e altura exatas de 40px |
| | `rounded-xl` | Aplica cantos arredondados de 0.75rem nos cards |
| | `rounded-full` | Deixa o elemento inteiramente circular (badges/avatares) |
| **Bordas & Sombras** | `border` | Adiciona borda padrão de 1px |
| | `border-slate-700` | Define a cor da borda para harmonizar com o modo escuro |
| | `border-l-4` | Adiciona uma borda espessa apenas no lado esquerdo |
| | `shadow-lg` | Aplica uma sombra projetada destacada no elemento |
| **Flexbox & Grid Layout** | `flex` | Transforma o container em um layout Flexbox |
| | `flex-col` | Organiza os itens do Flexbox em coluna vertical |
| | `items-center` | Alinha os itens do flex centralizados no eixo cruzado |
| | `justify-between` | Distribui os itens com espaçamento máximo entre eles |
| | `grid` | Transforma o container em um grid bidimensional |
| | `grid-cols-1` | Define 1 coluna para telas menores |
| | `gap-6` | Define o espaçamento entre células do Grid |
| **Responsividade (Breakpoints)** | `sm:grid-cols-2` | Define 2 colunas em telas pequenas (small >= 640px) |
| | `md:flex` | Exibe o elemento como Flexbox a partir de telas médias (>= 768px) |
| | `lg:grid-cols-4` | Define 4 colunas para telas grandes (large >= 1024px) |
| | `lg:col-span-2` | Faz o card de projetos ocupar 2 colunas no grid |
| **Posicionamento & Efeitos** | `sticky top-0` | Fixa o cabeçalho no topo durante a rolagem |
| | `backdrop-blur-md` | Aplica um efeito de desfoque de vidro (glassmorphism) |
| | `transition-colors` | Suaviza a transição de cores em ações hover |

## 🛠️ Como Executar o Projeto

1. Faça o clone deste repositório:
   ```bash
   git clone https://github.com/seu-usuario/projeto-tailwind.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd projeto-tailwind
   ```
3. Abra o arquivo `index.html` em qualquer navegador web de sua preferência.
